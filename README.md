#        ISSA TOOL

An all-in-one desktop app for **Call of Duty video editors**. Record gameplay, pull AI depth maps, trim your clips, and drive the in-game theater — all from one place.

> Windows only · still in beta (expect bugs)

## Features

- **Downloader** — grab music and audio for your edits
- **Recording tool** — capture a game window or a capture card straight to MP4, with optional AI depth recorded alongside
- **ProRec** — Drag and Drop ur clip into prorec converter
- **Clip trimmer** — a simple timeline to cut and arrange clips
- **COD Launcher** — launch your games with issa tool's theater tools and editing mods baked in:
  - BO1 (Plutonium), BO2 (Redacted), BO3, and more
  - free-cam, bot spawning, custom scenes, cinematic depth of field
  - clean recordings (no HUD/menus baked in)
- **MultiConsole** — send console commands to a running game

## Install

1. Download the latest **`issa tool setup.exe`**.
2. Run it and choose where to install (default: `%LOCALAPPDATA%\Programs\issa tool`).
3. Launch issa tool from the Start-menu or desktop shortcut.



## Notes

- **Antivirus:** issa tool hooks into games to power its theater/editing features, which some antivirus flags as a false positive. It's safe — allow it, or add its folder to your AV exclusions.
- **Themes:** pick a look in Settings; the in-game theater follows your theme.
- **Background mode:** turn it on in Settings to keep issa tool running in the system tray after you close the window.
